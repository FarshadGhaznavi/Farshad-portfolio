# پورتفولیوی مهندسی برق — فایل شروع

## فایل‌ها
- `index.html`: محتوای صفحه، بخش‌ها، متن‌ها و کارت‌های پروژه
- `style.css`: رنگ‌ها، چیدمان و ظاهر صفحه
- `script.js`: دکمه تغییر زبان فارسی/انگلیسی
- `assets/resume.pdf`: محل قرار دادن فایل رزومه PDF

## تغییرات اولیه
1. در `index.html` نام، معرفی، مهارت‌ها و شرح پروژه‌ها را ویرایش کن.
2. ایمیل نمونه `your.email@example.com` را با ایمیل خودت جایگزین کن.
3. لینک LinkedIn را با لینک واقعی پروفایل خودت عوض کن.
4. فایل رزومه PDF را داخل پوشه `assets` با نام `resume.pdf` قرار بده.
5. نمونه‌های تصویری فعلی، طرح‌های گرافیکی موقت هستند؛ آن‌ها را با تصاویر پروژه‌های واقعی و قابل انتشار خودت جایگزین کن.

## انتشار رایگان با GitHub Pages
1. یک حساب در https://github.com بساز یا وارد شو.
2. یک repository جدید با نامی مثل `farshad-portfolio` بساز و Public را انتخاب کن.
3. فایل‌های `index.html`، `style.css`، `script.js` و پوشه `assets` را آپلود کن.
4. در repository وارد Settings → Pages شو.
5. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن؛ branch را `main` و folder را `/(root)` قرار بده و Save بزن.
6. بعد از چند دقیقه آدرس سایت در همان بخش نمایش داده می‌شود.

نکته: تا پیش از جایگزینی اطلاعات نمونه و انتشار در GitHub Pages، این سایت آدرس عمومی فعال ندارد. هیچ اطلاعات محرمانه مشتری یا نقشه‌ای را بدون اجازه منتشر نکن.
